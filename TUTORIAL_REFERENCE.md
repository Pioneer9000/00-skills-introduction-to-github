# Tutorial Reference Files

This directory contains reference files showing what you'll create during the GitHub Skills tutorial.

## PROFILE.md (Created in Step 2)

When you complete Step 2 of the tutorial, you'll create a file called `PROFILE.md` in the root of your repository on the `my-first-branch` branch.

The file should contain:

```
Welcome to my GitHub profile!
```

This simple file serves as your first commit and introduces you to:
- Creating files in GitHub
- Writing Markdown
- Making commits
- The concept of a profile README

After completing the tutorial, you can expand this to create a real profile README for your GitHub account by creating a repository with the same name as your username!
